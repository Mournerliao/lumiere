# Public perfect-HDR-fidelity Is Fixed Target

Lumiere's public release target is Public perfect-HDR-fidelity and should not be renamed or downscoped to SDR-compatible fidelity. SDR-compatible output may exist as a fallback or auxiliary path, but the first public release must prove visual-match output and at least one HDR-preserved supported output path with target-aware HDR state, output contracts, compatibility evidence, and Windows validation.
