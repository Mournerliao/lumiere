# Product Roadmap

Status belongs in `state/CURRENT.md`; this roadmap defines sequence and scope only.

## HDR-Aware MVP

Deliver native region/fullscreen capture, main/tray/shortcut entry points,
FP16/scRGB-oriented preview, target-aware HDR readiness, and one official compatible
output path: sRGB Visual Match for clipboard and folder delivery.

Release requires Windows runtime evidence, fixed-scene visual-match evidence, honest
copy, and a traditional setup executable validated on a non-development machine.

## One HDR-Preserved Export Path

Choose one format and one named viewer before implementation or public claims.
Define source/destination color semantics, conversion, metadata, and viewer assumptions,
then gather target-aware Windows hardware evidence. JPEG XR remains only a candidate.

## Broader Compatibility

Expand named viewers, mixed HDR/SDR topologies, DPI/accessibility hardening, longer
stability runs, and the support matrix only after one narrow path has evidence.

## Non-Goals

Lumiere is not a general image editor, HDR mastering tool, cloud sharing product,
or promise of display-independent identity across all monitors and viewers.
