# 0001: MVP-First HDR-Aware Release

Date: 2026-07-03

## Decision

Lumiere's first release target is an MVP-first HDR-aware Windows screenshot tool, not a broad HDR-preserved fidelity release.

## Context

The project had accumulated a heavy validation and planning process around a broad HDR fidelity claim. That process protected against overclaiming, but it also made the first usable release harder to reach.

## Consequences

- The MVP focuses on fast native screenshots, honest HDR state, FP16/scRGB preview direction, and compatible output.
- HDR-preserved export moves to a future milestone with a narrow supported path and explicit viewer validation.
- Documentation should guide current development directly instead of routing work through generated planning artifacts.
