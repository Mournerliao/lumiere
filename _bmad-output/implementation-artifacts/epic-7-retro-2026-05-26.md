# Epic 7 Retrospective: Tray, Hotkeys, and Background Workflow

## Epic Review

Epic 7 completed the tray menu, global hotkeys, and background/minimize-to-tray workflow for Lumiere's MVP. The epic moved Lumiere from a window-only capture tool to a background-capable utility that stays available through system tray and keyboard shortcuts after the user leaves the main window.

Completed stories:

- 7.1 Add Tray Menu with Status and Commands
- 7.2 Open Main Window and Settings from Tray
- 7.3 Register Global Capture Hotkeys
- 7.4 Support Background and Minimize-to-Tray Workflow
- 7.5 Quit Cleanly from Tray

## What Went Well

- Architecture boundaries held consistently: Win32 tray/hotkey details stayed in `Lumiere.Infrastructure.Interop`, command routing stayed in `Lumiere.App.Core`, and app orchestration stayed in `Lumiere.App`.
- No parallel implementations were created: tray and hotkey capture commands reuse the existing single-session guard and command coordinator.
- UI thread protection is now enforced: all tray and hotkey commands dispatch through `DispatcherQueue` before mutating app state.
- Startup visibility regression was caught and fixed in Story 7.4: background integrations now attach after the first window activation.
- Test coverage grew from 265 to 273 tests with focused hotkey parsing and conflict detection tests.

## Challenges

- All 5 stories were created and completed on the same day (2026-05-25), which may indicate shallow review depth.
- Every story is marked "Windows CI-pass only" with no actual Windows manual validation performed.
- The 5 stories share nearly identical file lists, creating risk of inter-story code conflicts.
- 4 technical debt items from deferred-work.md targeted Epic 7 but were not addressed.

## Key Learnings

- Reusing the existing capture command path (from Epic 4) made tray/hotkey integration straightforward. The single-session guard worked without modification.
- The `ITrayMenu` abstraction with typed command events and immutable snapshots kept Win32 details out of app code. This pattern should extend to future interop boundaries.
- Background mode requires careful lifecycle management: hide on close, explicit Quit path, and deterministic resource cleanup. The startup visibility fix shows this is fragile.
- Deferred technical debt compounds: 4 items from Epic 4/5 that targeted Epic 7 remain unresolved and are now higher risk for Epic 8's release validation.
