Lumiere UX Design Directions

Historical overlay direction board. The current MVP route uses direct monitor capture and release-to-copy; confirm-style controls below are retained only as exploratory/fallback references.

Native Minimal

Closest to Windows Snipping Tool: sparse controls, a small trust badge, and content-first crop selection.

Best for

  • First MVP overlay
  • Lowest learning curve
  • Calm capture flow

Tradeoff

Advanced diagnostics are less visible unless explicitly opened.

Trust Strip

A persistent top strip makes preview trust impossible to miss while preserving the main crop area.

Best for

  • HDR correctness emphasis
  • Clear target display context
  • Multi-monitor awareness

Tradeoff

More UI is present during selection, though it stays edge-aligned.

Diagnostics Rail

A right-side rail keeps technical evidence visible for power users and developers without blocking crop selection.

Best for

  • Phase 0 validation
  • Developer builds
  • Advanced troubleshooting

Tradeoff

The rail can feel too technical for a default user-facing MVP.
