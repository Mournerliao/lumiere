Lumiere UX Design Directions

Six directions derived from the v0 MVP reference and translated toward native WinUI/Fluent. These are decision aids, not production UI code.

Evaluate: speed · trust · native utility feel · recovery

Makes the overlay the hero. Best for defining crop behavior, invalid states, and minimal chrome.

This should be paired with Direction 1 or 2 for main panel. It is a focused overlay treatment, not a whole app shell direction.
