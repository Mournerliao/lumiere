# Perfect HDR Fidelity Public Release Is Fixed Target

Lumiere's public release target is Perfect HDR Fidelity Public Release and should not be renamed or downscoped to SDR-compatible fidelity. SDR-compatible output may exist as a fallback or auxiliary path, but the first public release must prove visual-match output and at least one HDR-preserved supported output path with target-aware HDR state, output contracts, compatibility evidence, and Windows validation.
